# Hafta 12 · Demo 1 — Birim test koşucusu (S16 sonuçları)

İki küçük güvenlik fonksiyonunu (`girdi_dogrula`, `guvenli_topla`) **test kartlarıyla**
sınar; her test için amaç/gözlenen/karar basar. Çıkış kodu = başarısız test sayısı.

## Çalıştırma
CMake ile derleyin, sonra `bin/<platform>/birim_test` çalıştırın.

## Güvenlik
Saf hesap; dosya/ağ/sistem işlemi yok.
