# Hafta 14 · Demo 1 — Kaynaktan kaynağa gizleme (Tigress)

`erisim_ver` fonksiyonunu **Tigress** ile kaynaktan kaynağa gizler (kuruluysa):
dönüşüm hattı + davranış doğrulama + `objdump` ile maliyet + iki tohumla çeşitlendirme.
Tigress kurulu değilse indirme/lisans yönergesini gösterir ve yerel örneği ölçer;
aynı kuralların **el ile** çalışan sürümü `week-09/01-manuel-gizleme`'dedir.

## Çalıştırma
```sh
sh tigress-hatti.sh      # Tigress'i https://tigress.wtf adresinden indirin (akademik kullanım ücretsiz)
```

## Güvenlik
Yalnız bu klasörde çalışır; ağa çıkmaz; kendi kodunu gizler/ölçer. Geçici dosyalar silinir.
